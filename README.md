# Freddy's Angels — Feestweek 2026 Pool

Voorspelpool rond de Feestweek Vijfhuizen (7–11 september 2026).

## Structuur
- `fw2026-deelnemer.html` — deelnemerspagina (voorspellingen invullen, ranglijst)
- `fw2026-admin.html` — beheerpagina (uitslagen invoeren, teams/spellen beheren)
- `sql/` — database-schema (Supabase Postgres)
- `supabase/functions/` — Edge Functions

## Stack
- Vanilla HTML/CSS/JS
- Supabase (Postgres + Auth + Edge Functions)
- Hosting: GitHub Pages
